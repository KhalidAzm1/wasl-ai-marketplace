## كيف تركّب أي وكيل في 4 خطوات

1. اختر الوكيل الأقرب إلى مهمتك من الجدول وافتح ملفه.
2. أنشئ Project جديدًا في Claude أو ChatGPT وسمّه باسم واضح.
3. انسخ كل ما داخل صندوق **التعليمات** في ملف الوكيل والصقه في **Instructions** ثم احفظه.
4. جرّب المثال التطبيقي الموجود تحت **جرّبه الآن** داخل المشروع.

- في Claude: claude.ai ← Projects ← New project ← سمِّه ← Instructions ← Add ← الصق التعليمات ← Save
- في ChatGPT: chatgpt.com ← علامة + بجانب Projects ← سمِّه ← … ← Project settings ← Instructions ← الصق ← Save

**⚠️ قبل الاستخدام**

- لا ترفع بيانات عملاء أو موظفين أو عقودًا أو سجلات حقيقية إلا في حساب الشركة المعتمد وبعد موافقة فريق الأمن السيبراني.
